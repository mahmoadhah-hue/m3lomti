# 📓 مدوّنة تعلّمي

تطبيق ويب عربي لتدوين ما تعلمته ومراجعته.

## المزايا
- تدوين يومي (مجال، مصدر، صعوبة) + تسجيل صوتي يتحول لنص
- هدف يومي، سجل أخطاء وحلول، شرح فينمان، خطوة تطبيق خلال 24 ساعة
- تقويم بلا حدود + قائمة لكل يوم + قائمة خارجية
- مراجعة متباعدة وبطاقات ذاكرة
- بحث وربط معرفي وكبسولة الزمن
- عداد الالتزام وتقارير أسبوعية وشهرية وتحدي 30 يوم

## التشغيل
افتح `index.html` في المتصفح. البيانات تُحفظ محلياً في المتصفح.

## ملفات المشروع
- `index.html` التطبيق كامله
- `icon.svg` أيقونة التطبيق
